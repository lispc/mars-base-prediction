# 13 · 自持性评估（lunar 版：2045 年达标裁决）

> 对照 `lunar/00-设定与统一口径.md` §11 的三条件，评估 2045 年（250 人）的达成度。
> **结论先行：三条全部达标，其中"C/N 自给 ≥85%"是唯一置信度中等项**——
> 它系于 PSR 储量这一全项目第一资源风险。月球自持的特征是：
> **物流维度天然容易（3 天供应链）、资源维度天然更硬（无大气，碳氮稀缺）**——
> 与火星版恰好镜像。

## 1. 评估基准（lunar/00 §11）

| # | 条件 | 阈值 |
|---|---|---|
| C1 | 物质闭环 | 水/氧 100%；食物热量 ≥90%；建材 ≥90%；**光伏板 100% 本地（月球特有）**；C/N 新增需求 ≥85% 来自 PSR |
| C2 | 补给流量 | ≤0.25 t/人/年 |
| C3 | 经济可承受 | 维持费 ≤$1.0B/年，**且商业收入覆盖 ≥20%（月球特有后半句）** |

## 2. C1 物质闭环：**达标**（C/N 项置信度中等）

| 项目 | 2045 状态 | 依据 |
|---|---|---|
| 水 | 100%（PSR 冰 + 循环 ≥99%） | `lunar/04`/`lunar/06` |
| 氧 | 100%（MRE，月壤氧近乎无限） | `lunar/04` §4 |
| 食物热量 | ≥90%（ESF 受碳源约束爬坡至此；低于火星 breakthrough 的 95%——碳约束更硬） | `lunar/06` §8 |
| 建材 | ≥90%（月壤烧结/浇铸/土工，最易本地化项） | `lunar/05`/`lunar/10` |
| 光伏板 | 100% 本地（2036 产线起，月球特有成就——火星版做不到） | `lunar/03` §5 |
| C/N 新增需求 | **≥85%（条件性达标）** | `lunar/04` §6 爬坡表 |

**C/N 项的诚实标注**：85% 达标的置信度为"中"，完全系于 2029 年 G1 判决的 PSR 储量/形态。
若 G1 不利（S1 情景），C/N 项退回"进口长期化"，C1 判定降级为部分达标、评估顺延 2048。
这是本评估中**唯一的资源不确定性**——水的开采风险与 C/N 的开采风险是同一个（都来自 PSR），
属于单点依赖（`lunar/11` LR01 为塔尖风险）。

## 3. C2 补给流量：**达标**（余量紧）

2045 年（250 人）维持性补给预算：

| 类别 | t/人/年 | 来源 |
|---|---|---|
| 食物残余（补剂/调味/特色蛋白/种子菌种等） | ~0.15 | `lunar/06`（略高于火星 breakthrough——C/N 补充压力） |
| 制造残余（先进 SoC/药品/精密光学/碳基功能材料） | ~0.007 | `lunar/10` §9（全站 1.4–2.3 t/年 ÷250 人） |
| 药品 | ~0.01 | `lunar/10` §9 |
| 先进电子（SoC/存储/精密光学） | ~0.02 | `lunar/10` §5 |
| 个人物品/轮换相关 | ~0.05 | `lunar/08`（季度快递模式，低于火星的 0.08——3 天物流下"囤货"需求小） |
| **合计** | **~0.24 t/人/年** | **阈值 0.25 → 达标，余量仅 ~4%** |

**与火星两版对比**：火星 baseline 0.63+（未达）、breakthrough 0.33（阈值 0.35）、
lunar 0.24（阈值 0.25）——月球绝对值最低，但**余量也最薄**；主导项依然是食物残余。
守住余量的关键：ESF 碳源供给（C/N 项）与季度快递的稳定性。

## 4. C3 经济可承受：**达标**（含收入项，月球特有）

2045 年账（`lunar/09` §4/§5 口径）：

| 项目 | $B/年 |
|---|---|
| 运输（维持性货运+客运摆渡，维持费第一大项） | ~0.6–0.7 |
| 补给硬件采购 | ~0.1 |
| 地球遥操作班组（~60 人三班制）+ 地面运行 | ~0.15 |
| **维持费合计** | **~$0.9–1.0B（阈值 $1.0B → 达标）** |
| 收入：科研托管+数据订阅+媒体权（2042 年前已锁约） | ≥0.2 |
| 收入：旅游（$50M/人 × 10–20 人）+ 制造出口（光伏/推进剂） | +0.3–0.9（上行，不进验收口径） |
| **收入覆盖（验收口径=现金+不可撤销合同）** | **≥20% → 达标（合同层独立成立，旅游落空也不破坏）** |

月球版特有的结构性优势：**遥操作人力从地球"租用"**（年省 ~$0.75B vs 随船自带施工人力，
`lunar/09` §7）——这是维持费能压进 $1.0B 的主因，也是火星物理上做不到的（光速延迟）。

## 5. 综合结论

| 条件 | 判定 | 置信度 | 最敏感依赖 |
|---|---|---|---|
| C1 物质闭环 | ✅ 达标（C/N 项条件性） | 中高（C/N 项：中） | PSR 储量（LR01） |
| C2 补给流量 | ✅ 达标（余量 ~4%） | 中 | ESF 碳源、快递稳定性 |
| C3 经济可承受 | ✅ 达标（维持费余量 ~10%，收入合同层独立达标） | 高 | 遥操作班组成本 |

**总评**：2045 年月球基地以 250 人规模实现"合理经济负担下的自持"——
与火星 breakthrough 版（2042、160 人）几乎同期达成，但达成路径的约束结构完全不同：
火星的自持赌的是**电力与农业**（能量约束），月球的自持赌的是 **PSR 挥发分**（资源约束）。
2045–2050 进入"定居点化"（450 人、地下城、出口经济），见 `lunar/14`。

### 与火星版的镜像总结

| 维度 | 火星（breakthrough） | 月球 |
|---|---|---|
| 物流 | 26 个月窗口、3 天撤离不可能 | **随时补给、3 天可撤离（天然宽松）** |
| 能量 | 电力是第一约束（B1 解决） | 长夜是约束（同一 B1 解决，且更彻底） |
| 资源 | 大气 CO₂ 免费、水冰浅表 | **C/N 稀缺、水集中于 PSR（更硬）** |
| 自持第一风险 | 电力扩张节奏 | **PSR 储量/形态** |
| 收入 | 无 | **旅游/科研/制造（特有）** |

## 6. 敏感性

| 假设翻车 | 后果 | 保护机制 |
|---|---|---|
| PSR 储量/形态不利（LR01） | C/N 项破 → C1 降级、评估顺延 2048；进口长期化 +$6B/24 年 | 2029 G1 前置判决；备用 PSR；地缘政治冗余（≥2 PSR） |
| 月产光伏爬坡失败 | C1 特有项破；光伏进口长期化 | 影响有限（运输便宜）；产线 2 期冗余 |
| ESF 碳源不足 | 食物项回 0.3+ t/人/年 → C2 破 | 进口碳储备缓冲（50 t 石墨/干冰，8–10 年寿命）；PSR 扩产 |
| 运输不降价（$80M/艘不降） | C3 +~$0.2B/年 | 余量吸收；航班化装载率优化 |
| 旅游需求落空 | 收入上行消失 | **验收口径已剔除旅游**（合同层独立达标）——设计时即为防此项 |
