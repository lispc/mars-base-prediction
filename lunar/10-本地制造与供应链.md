## 1. 背景与需求

### 1.1 问题定义：三个松绑与一个收紧

- **松绑一（时间）**：无窗口 + 3 天航程 + 1.3 s 延迟。下单→到货正常 2–4 周，失效件"快递式"补货，地球工程师可遥操作排故——火星版"深库存+冗余+本地再造"三层防线中，第一层（深库存）几乎可以拆掉。
- **松绑二（价格）**：月面交付单价 $0.8M/t（2030）→ $0.5M/t（2040）→ $0.35M/t（2050）（lunar/00 §6），全程低于火星版最低档（$0.67M/t）。"运费超过货值"的阈值下降但未消失——**本地化论点从"生存必需"变为"经济优化+自持达标"**。
- **松绑三（工艺环境）**：超高真空（~10⁻¹⁰ Torr）免费、无尘暴、无高氯酸盐毒性，多条地面高成本工艺边际成本骤降（§4）。
- **收紧一（碳/氮）**：一切含 C/N 制造品（聚合物、弹性体、润滑剂、溶剂、碳纤维复材）失去火星的"无限大气 CO₂"底座。两版制造哲学互为镜像：**火星版"凡能电解大气的都能本地化"，月球版"凡含碳氮的都要省着用"**。

本地制造的目标排序因此调整为：

1. 支撑 lunar/00 §11 的 2045 自持条件：建材 ≥90%、**光伏板 100% 本地**、补给流量 ≤0.25 t/人/年；
2. 低价值密度品类（建材、金属母材、玻璃/纤维、光伏板）转本地，舱位留给永远进口品；
3. 以"6 周库存 + 本地再造 + 快速补货"替代深库存，释放质量与资金（§7）；
4. **2045 年后反转角色**：从进口替代走向出口制造，为收入覆盖 ≥20% 提供物质底座（§10，接口 `lunar/14`/`lunar/09`）。

### 1.2 需求侧测算：2045 年（250 人）设计点

年度制造品流量估算。相对火星版设计点（2042 年 125 人）的结构性变化：B4' 遥操作兜底使备件消耗率进一步下降；食物归 `lunar/06`；聚合物改列"进口母粒+回收"；新增光伏板一项（本地产，lunar/03 §5.3 口径：内部扩容 ~50–100 kWe 铭牌/年 + 更换备板，产线 ≥400 kWe/年 的富余产能转出口，§10）。

| 类别 | 年需求量（估算） | 价值密度 | 本地化策略 |
|---|---|---|---|
| 建筑结构材料（烧结砖/玻璃/纤维/拱件） | 600–1000 t | 极低 | 全部本地（属 `lunar/05` 范围） |
| 光伏板（基板/电池片/电极/封装） | 20–50 t | 中 | **2036 起全部本地（§3.1）** |
| 金属结构件/支架/管件 | 20–50 t（自用；MRE 产能富余见 §3.2） | 低 | 2036 起 MRE 母材 + 车间成形 |
| 机械备件（齿轮、轴、阀体、密封座） | 2–6 t | 中 | 增材+机加本地 |
| 线缆/接插件/简单电气件 | 2–4 t | 中 | MRE 铝本地拉丝/装配 |
| 玻璃/陶瓷（窗、器皿、绝缘件） | 5–12 t | 低 | 2033 起本地（§3.3） |
| 聚合物件（管道、容器、薄膜、密封） | 3–8 t | 中 | **进口母粒 + 本地成形 + 闭环回收（C5）** |
| 电子模块（电源、控制器、传感器、线束） | ~1.2 t（更换流量） | 极高 | 2040 起 ~80%（按数量）本地再造（B5'） |

| 药品/医疗耗材（含 B3' 防护药物） | 0.5–0.8 t | 极高 | 永远进口（6 周期滚动补货） |
| 精密光学/超高精密仪器件 | 0.03–0.05 t | 极高 | 永远进口 |

结论与火星版同构但程度更深：按**质量**计主战场是建材、金属与光伏（~97% 质量，月球多了光伏）；按**价值**计，月产光伏与金属增厚本地侧，"永远进口"价值占比进一步压缩——决定 §8 双口径表。

## 2. "进口替代"三层级模型（月球版）

### 第 0 层（永远进口，2050 后亦然）

判据与火星版一致（超长供应链+极高价值密度 / 极限精度 / 法规级认证），成员有一处月球特有扩充：

- **先进 SoC 与存储器**：需求 <100 kg/年，~1 µm 本地制程与地球先进制程差 5–6 代，不追赶；策略同火星版（FPGA/通用裸片软件定义压需求，§5）。
- **药品与疫苗**：250 人年需求 ~0.5–0.8 t（含 B3' 防护鸡尾酒），GMP 不可本地化。**月球版利好**：6 周期滚动补货使效期管理从"60 个月深库存的损耗博弈"变为常规冷链周转（§7）。
- **精密光学与超高精密仪器件**（相机物镜、激光陀螺、陀螺级轴承）。
- **碳基功能材料（月球特有扩充）**：特种聚合物母粒（PEEK/氟橡胶/环氧）、弹性体密封件、全合成润滑剂、碳纤维——分子链长、用量小（合计 <1 t/年）、本地没有碳源余量。**这是唯一"相对火星版变长"的第 0 层清单**（C5/C9）。
- **高性能合金母材**（高温合金、铍铜等）：<200 kg/年。

### 第 1 层（2031–2036 本地化）

判据：工艺步骤 ≤3 步、原料为月壤/PSR 挥发分直接可得、容错率高。相对火星版**整体提前 2–4 年**（连续补给使设备随需随到）：

- **月壤建材与覆土结构**：烧结砖、土工织物袋装月壤（`lunar/05`）；
- **玻璃/陶瓷/纤维**：浇铸玻璃、烧结陶瓷绝缘件、玄武质纤维拉丝（§3.3）；
- **结构件与简单机械**：金属增材 + 钣金 + 真空环境焊接（§4）；
- **线缆导体**：MRE 铝拉丝（2036，火星版为 2037 MRE 铜铝）。

### 第 2 层（2036–2040 本地化）

判据：需要冶金/化工流程或洁净工艺——B1' 电力宽松使能耗判据失效，分界仍为"是否需要催化剂/超纯原料/无尘环境"：

- **金属母材**：MRE 产混合金属 + 本地精炼分选为钢/铝/硅（2036 规模化，§3.2）；
- **光伏电池**：玻璃基板 + 硅提纯 + 真空沉积全线（2036，§3.1）——火星版无此项；
- **基础化学品**：硫酸（月壤硫）、盐酸、烧碱（氯碱电解；**火星版"兼作高氯酸盐治理出口"的功能在月球不存在**，产能只为工艺自用）、双氧水/异丙醇（2040 起部分本地提纯，§5.3）；
- **电子备件**：B5' 电子车间产品谱（2040 达产，§5）。

明确不进入第 2 层的：**一切大宗聚合物合成**（碳约束，C5）；PVC/PET/尼龙（同火星版结论）；光刻胶与高纯显影液（第 0 层管理）。

## 3. 月球制造的三条独特路径

### 3.1 月产光伏电池（C3，接口 `lunar/03`）

**为什么月球可以而火星不行**：火星尘暴使光伏只是补充能源，没有本地制造的需求牵引；月球极区山脊光照率 ~70–90%（lunar/00 §4），光伏是 B1' 之外的第二能源支柱且扩容持续到 2050 后——需求、原料（SiO₂ ~45 wt%）、工艺环境（超高真空镀膜）三者齐备。工艺链四步与设备/产能口径采用 `lunar/03` §5.3，本文档补充供应链视角：

| 工序 | 方案 | 原料/来源 | 备注 |
|---|---|---|---|
| 基板 | 月壤熔融玻璃板（~2 mm） | 月壤直接熔融 | "moonglass"路线，地面已验证 |
| 半导体层 | 非晶/微晶硅薄膜（真空蒸镀/溅射） | MRE 冶金硅 → 电池级提纯（>99.999% 地面已演示） | 文献保守效率 6–9%（[综述](https://www.planetarysunshade.com/s/Fix-2021.pdf)），产线设计目标 ≥12–15%（lunar/03 §5.3），不追空间级 30% |
| 电极/导线 | MRE 铝（溅射/丝印/拉丝） | MRE 联产 | Blue Alchemist 已演示电池+导线 |
| 封装 | 月壤玻璃盖板 + 真空层压 | 本地 | 比质量 50–100 kg/kWe 是可接受代价（运输成本归零） |

- **硅提纯路线（本文档域内工序）**：MRE 粗硅 → 酸洗 + **真空蒸馏脱除 Al/Ca/P 等高蒸气压杂质**（§4）+ 定向凝固 → 电池级。电子级（9N+）2045 前不追求——这是光伏线与 B5' 电子车间的原料梯级分界（§5.3）。
- **产能与经济性（引用 lunar/03 §5.3 口径）**：产线交付 ~15 t、电力 100 kWe（2036）→ 200 kWe（2040）；产能 50 kWe 铭牌/年（2036）→ 200（2040）→ **≥400 kWe/年（2045）**，覆盖内部扩容（铭牌 700→1000 kWe，2036→2045）+ 备板更换后仍有富余——**富余产能即 §10 出口的物质底座**。扩容边际成本从进口期 ~$0.5–0.8M/kWe 降至全本地 ~$50–100k/kWe 等效，光伏扩容从资本项变运维项——这是 lunar/00 §7"扩容边际成本骤降"的机制。
- **现实锚点**：Blue Alchemist 目标"每个定居点 ≥1 MW 月面光伏"（[Aerospace America](https://aerospaceamerica.aiaa.org/departments/from-moon-dust-to-moon-colonies/)）；TU Berlin/JPM Silicon 月壤玻璃-硅电池路线（[TU Berlin](https://www.tu.berlin/en/raumfahrttechnik/news-details/tu-berlin-und-jpm-silicon-erhalten-forschungsfoerderung-der-deutschen-raumfahrtagentur-im-dlr-zur-fertigung-von-solarzellen-mit-mond-regolith)）；月面真空直接蒸镀电池的早期概念（[LPI ISRU'97](https://www.lpi.usra.edu/meetings/isru97/pdf/2407.pdf)）。

### 3.2 MRE 联产金属：下游精炼与产品谱（C2，接口 `lunar/04`）

月壤氧化物 ~42–45 wt%、无高品位矿床，"免选矿一步法"MRE 是天然正解，且**月球是 MRE 工艺的原始场景**——火星版引用时需做铁含量修正，本版直接采用。炉群部署、能耗（设计点 ~8 kWh/kg O₂）与产能口径全部归 `lunar/04` §4.3：2033–2035 中试（~80 kWe，年产 O₂ ~28 t + 混合金属 ~35 t）→ 2036–2039 规模化（~350 kWe，O₂ ~200 t + 金属 ~250 t + 光伏级硅原料 ~30 t/年）→ 2040–2045 工业期（~700 kWe，O₂ ~450 t + **金属 ~550 t/年** + 硅 ~150 t/年）。本文档负责炉群下游：

- **精炼分选**：MRE 阴极混合金属（Fe/Si/Al/Ti）→ 感应炉精炼调成分 + **真空蒸馏/真空脱气二次提纯**（§4，替代火星版的氢还原精炼角色——氢在月球更金贵）→ 铸棒/制丝/连铸连轧。硅的分选精炼供 §3.1 光伏线（lunar/04 已约定"分选精炼归 lunar/10"）。
- **产品谱**：铝（线缆导体、光伏电极、结构梁——南极高地岩性使铝占比高于火星版预期）、钢系（结构件、备件母材）、硅（光伏原料）、钛（小量特种件）。
- **熔渣**：玻璃质熔渣（每 1 t O₂ 联产 ~1.3 t）即铸即用，作建材骨料/铸块（接口 `lunar/05`），零废弃。
- **产能与需求的差**：2045 年金属产能 ~550 t/年，基地自用仅 ~50–100 t/年（§1.2）——**富余产能是 §10 结构件出口与第二定居点建设的储备**，这是月球版"工业自我繁殖"（lunar/03 §5.4）在制造域的对应物。
- **选址协同**：炉群排气羽流在无大气下直接污染周边光学面与光伏板，工业区布局须与光伏场/着陆场分区（接口 `lunar/02`，风险 §12 R4）。

### 3.3 月壤玻璃与玄武质纤维（C4）

月海玄武质月壤的氧化物配比接近地球玄武岩纤维原料窗口（SiO₂ 45–50%、Al₂O₃ 12–16%、FeO 10–18%、CaO 8–12%），**可直接熔融拉丝、无需配料调和**。现实验证：中科院新疆理化所月壤模拟物连续纤维强度 >1400 MPa（[CAS](http://english.xjipc.cas.cn/NEWS/202207/t20220705_307783.html)）；ESA/ETH 用 JSC-2A 模拟物拉丝并完成纤维增强居住舱概念（[ETH IAC-22](https://www.research-collection.ethz.ch/bitstream/handle/20.500.11850/603678/IAC-22.pdf?sequence=4)、[ESA ACT](https://www.esa.int/gsp/ACT/doc/HAB/ACT-RPR-HAB-2018-IAC-Fibrous_Structure.pdf)）；玄武岩纤维耐温 -260~1250 °C，天然适配月面热循环。

**产品谱**：

| 产品 | 用途 | 启动时点 |
|---|---|---|
| 短切纤维 | 月壤混凝土/地质聚合物增强、3D 打印浆料增韧 | 2033 试点 |
| 连续纤维/织物 | 纤维缠绕压力容器内衬、缆索、遮阳结构、EVA 服防护层 | 2036 产线 |
| 玻璃纤维棉 | 阴影期隔热、HEPA 级滤材基底 | 2036 |
| 浇铸玻璃 | 窗、器皿、光伏基板（§3.1）、光学毛坯 | 2033 |

- **与聚合物的关系**：纤维增强 + 少量进口树脂即可替代大量纯塑料结构件——**纤维是 C5"聚合物推迟"的主要补偿手段**：以硅基材料+微量碳基粘结剂替代碳基本体材料。
- **拉丝塔设计**：漏板（铂铑合金，第 0 层进口消耗件，年 ~2–5 kg）+ 真空自然快冷成纤（地面靠水冷/风冷）；单塔 ~15 kW、年产连续纤维 20–50 t。

## 4. 真空作为工艺资产（C7，新增专章）

月面 ~10⁻¹⁰ Torr 级超高真空，在地面需扩散泵+分子泵+数月抽气才能获得。**"工艺真空免费"重构多条工艺的经济性**；IDA 地月经济研究亦将"月球真空比 LEO 更强更洁净"列为受访专家公认的制造卖点（[IDA D-13219](https://www.ida.org/-/media/feature/publications/d/de/demand-drivers-of-the-lunar-and-cislunar-economy/d-13219.pdf)）。

| 工艺 | 地面成本来源 | 月球形态 | 应用 |
|---|---|---|---|
| 蒸镀/溅射镀膜 | 真空室+泵组+抽气时间 | 露天/半开放工位直接沉积 | 光伏电池（§3.1）、反射镜镀铝、热控膜 |
| 真空蒸馏提纯 | 真空冶金炉 | 直接排放馏分 | 硅→电池级（§3.1）、MRE 粗金属精炼（§3.2） |
| 焊接/钎焊 | 保护气（Ar 进口消耗品） | **无氧化焊接**，免保护气 | 结构件、管道、天线 |
| 真空冶金脱气 | 真空感应炉 | 熔体直接暴露脱气 | 高致密铸件、低气孔率增材 |
| 粉末/纤维工艺 | 惰气保护 | 免保护 | 纤维拉丝（§3.3）、冷喷涂修复 |

**反面清单（真空不是免费午餐）**：

- **冷焊**：洁净金属接触面在真空下自发粘着——运动机构须固体润滑（MoS₂/DLC）或陶瓷轴承，液体润滑剂会挥发爬移；润滑剂因此列入第 0 层长期进口（§2）。
- **散热**：工艺设备纯辐射散热，MRE 炉、拉丝塔热设计按空间载荷范式（辐射板面积即质量）。
- **月尘**：静电吸附的锋利尘粒是镀膜洁净度与运动密封的头号敌人——真空工位仍需"尘闸"过渡区与局部正压保护：**"真空免费、防尘不免费"**。
- **工艺分工**：加压舱内工序（机加、电子车间）与月面真空工序（镀膜、蒸馏、焊接）的原则是"能露天则露天"——舱内容积是稀缺资源，真空不是。

**战略含义**：真空镀膜/提纯 + 月壤原料 + 廉价地月运输的组合，是 §10 出口叙事中"月球特产"（高纯材料、镀膜服务、大口径镀膜镜面）的工艺底座。

## 5. B5' 电子车间：2038–2040（C6）

参数逐字沿用 `breakthrough/00` §1-B5（~8 t、~40 kWe、覆盖电子备件按数量 ~80%/按价值 ~50%、~1 µm 直写 + 印刷电子 + FPGA/裸片烧录三线）；lunar/00 §3-B5' 的适配仅两处：**部署提前至 2038–2040**、**与月产光伏共用 MRE 硅原料**。

### 5.1 产品谱与覆盖边界

与火星版 §5.1 同构（L1 直写 / L2 印刷电子 / L3 FPGA 烧录；先进 SoC/DRAM/NAND 不追赶），不重复展开。月球版两点差异：

- **"去先进芯片化"设计规范提前到 2033 年**（火星版 2035）：2033 后上行设备的控制功能一律下沉到可本地再造的 MCU/FPGA 层级；
- **遥操作改变运行模式**：火星版 lights-out 依赖 B4 的 L4 自主 + 地球异步支持；月球版地球工艺工程师可**准实时遥操作**（1.3 s 延迟）参与调方与异常处置，车间人类编制从 2–3 人降为 **1–2 人兼职**，良率爬坡风险低于火星版。

### 5.2 无尘环境：月球尘对策（相对火星版的变与不变）

- **变（有利）**：无大气对流——尘只随活动（行走、行驶、着陆羽流）扬起；无尘暴季；月尘**无高氯酸盐毒性**，人员暴露风险与湿法除湿成本双降。
- **变（不利）**：月尘更锋利、静电吸附更强、0.16 g 下沉降更慢；气闸密封按**高磨损件**管理（密封座列入 B 级 6 周 + 本地机加再造）。
- **不变**：微环境隔离（SMIF/FOUP 月球版）、ISO 5 微环境 + ISO 7–8 外围、HEPA+静电双级除尘、光刻隔振与远离 MRE/建材窑——架构照抄火星版 §5.2，仅删除高氯酸盐条款。

### 5.3 化学品与硅片供应链

| 物料 | 2040–2042（初期） | 2042 起 |
|---|---|---|
| 硅片（prime 级 200 mm） | 进口（年 ~500–2000 片 ≈ 30–120 kg，6 周滚动+3 个月缓冲） | 继续进口；**太阳能级归光伏线，电子级 2045 前不追求**（§3.1 梯级） |
| 光刻胶/显影液 | 进口（年 ~30–50 kg，6 周期效期滚动） | 继续进口 |
| 湿法化学品 | 进口浓缩液本地稀释 | 部分本地提纯（硫酸/双氧水/异丙醇），覆盖 ~60% |

| 特种气体 | **比火星版更紧**：无大气可分馏——N₂/Ar 依赖 PSR 挥发分副产 + 尾气回收，初期部分进口 | PSR 规模开采后自给（接口 `lunar/04`） |

### 5.4 与 B4'/遥操作的无人化运行

车间 lights-out 设计与火星版相同，但自主等级要求从 L4 降为 **L2–L3 + 遥操作兜底**（lunar/00 §3-B4'）：机器人执行 FOUP 转运/上下料/点检，地球操作员轮班遥操作处理灵巧工序——火星版"机器人灵巧性边界"风险在月球版降级为中低。数字孪生 BOM（图纸/参数/比特流全量本地存储）机制不变。

## 7. "6 周安全库存"原则（C1，替代火星版 §7）

### 7.1 原则定义

补给链参数：随时可发 + 3 天航程 + 发射准备/排期 → 正常下单→到货 **2–4 周**；异常场景（运载器停飞排查、发射场中断）恢复按 4–6 周估计（多运载器/多发射场冗余下）。因此：

- **基准库存深度 = 6 周消耗量**（约 1.2 倍最大预期补货周期）；
- **A 级（生命攸关）加深至 12–26 周**：药品、ECLSS 关键不可再造件、堆控制主 SoC 冗余片、精密光学——深度取决于"本地再造兜底是否存在"：存在（如 MCU/电源层）则 6 周，不存在则 26 周；
- **B 级（任务攸关）6 周 + 本地再造兜底**：催化剂、压缩机密封、车规电机、通用电子器件；
- **C 级原材料化库存**（棒/板/丝材/晶圆/油墨/母粒）8–12 周，不做成品深库存。

### 7.2 释放了什么（相对火星版的量化）

| 维度 | 火星版（两个窗口原则） | 月球版（6 周原则） |
|---|---|---|
| 常备进口库存质量（250 人级口径） | A 级 60 个月 + B 级 26–36 个月 ≈ **40–80 t 级** | 6–26 周 ≈ **4–12 t** |
| 药品效期损耗 | 60 个月深库存 vs 生物制剂效期上限的结构性矛盾 | 6 周期滚动 FIFO，效期损耗基本消除 |
| 库存占用资金 | 库存货值 + 提前 3–5 年采购的资金成本 | 下降 ~90% |
| 失效预测依赖 | 无先验、靠不确定性带宽硬扛 | 快速迭代：实测失效率 1–2 个季度即收敛 |
| 单点脆弱性 | 错过一个窗口 = 26 个月裸露 | 单船失效 = 3 天后补发 |

**原则的前提与代价**：6 周原则把韧性从"库存"转移到**运输系统的可用率**——等价于强假设"联合体始终维持 ≥2 种可用运载器 + ≥2 个发射场"；其失效（运载器垄断、政治性断供）是 §12 R6 与 `lunar/11` 的政治风险项。**库存释放的资金不回笼为利润，而是转投本地制造产能**——把供应链弹性实物化的制度安排（接口 `lunar/09`）。

## 8. 本地化率爬坡表（重排，C8）

口径同火星版：**按质量** = 本地生产质量 ÷ 基地年物质总吞吐（经常性吞吐 + 上行资本设备摊销）；**按价值** = 本地生产物的地球采购等价值 ÷ 总经常性补给价值。

| 年份 | 常驻人数 | 按质量 | 按价值 | 主要增量来源 |
|---|---|---|---|---|
| 2031 | 12 | ~15% | ~5% | 水/氧 100% 本地、覆土建材、简单工具、FDM 件 |
| 2033 | 30 | ~35% | ~10% | 车间一期、MRE 中试、烧结砖上量、玻璃/纤维试点、ESF 投产 |
| 2036 | 60 | ~60% | ~25% | **MRE 规模化（金属母材）+ 月产光伏启动 + 建材 80%** |
| 2040 | 120 | ~75% | ~40% | **电子车间达产**、纤维/玻璃满产、食物热量自给 ~70% |
| 2042 | 160 | ~82% | ~48% | 电子化学品部分本地提纯、食物冲 90%、C/N 60% 来自 PSR |
| 2045 | 250 | **~90%** | **~55–65%** | 光伏板 100% 本地、建材 ≥90%、C/N 85% 来自 PSR |

**2045 双口径推导**（±5pp 不确定度）：

- **质量口径 ~90%**：经常性本地吞吐 ≈ 建材 ~700 t（2045→2050 扩建期，`lunar/05`）+ 食物干物质 ~51 t/年（250 人 × 0.62 kg/天 × 90% 本地）+ 金属/玻璃/纤维 ~80 t + 光伏增量 ~40 t ≈ **~870 t**；进口侧 ≈ 补给残余 250 × 0.15 t/人/年 ≈ 38 t + 上行资本设备摊销 ~40–60 t/年 ≈ **~90 t**。870/(870+90) ≈ 91%，取整 **~90%**（资本设备摊销计入分母，与火星版同约定）。
- **价值口径 ~55–65%**：本地侧 = 全部食物 + 建材 + 金属 + **光伏电力（月球特有高价值项）** + 电子件 50% 价值；残余进口 = 药品（高值）+ 先进 SoC + 碳基功能材料 + 精密光学 + 催化剂/光刻胶 + 食物补剂 + 个人物品 ≈ 总价值 ~35–45%。**光伏项使月球价值口径上限反超火星版**（55–60%）——尽管碳基残余更重。
- 与 lunar/00 §11 条件 1 核对：水/氧 100%、食物 ≥90%、建材 ≥90%、光伏板 100%、C/N ≥85% —— 全部含于上表 2045 行，无冲突。

| **合计** | **~1.4–2.3 t/年** | | | ≈ **0.006–0.009 t/人/年** | |

结论：

- **药品仍是按价值最大残余项**，但弹性设计逻辑改变：不再是"深库存抗窗口"，而是"多供应商 + 周期货班 + 效期零损耗 + 26 周战略缓冲"——失效场景从"断供 26 个月"变为"断供 6–26 周"，风险量级本质性下降；
- **碳基功能材料是月球特有的第二瓶颈**（火星版无此项）：不危及生命但卡住装备翻新能力（密封件、软管、润滑），缓解靠"设计端去碳基化"（金属波纹管密封、固体润滑、纤维增强硅基复材）而非本地化合成；
- 制造域残余 ~0.006–0.009 t/人/年，占 lunar/00 §11 的 0.25 t/人/年阈值仅 **~3%**——**制造不是月球自持的物质瓶颈**；真正残余风险是政治性断供（R6），属 `lunar/11` 范围。

## 10. 2045 后出口制造（C10，新增，接口 `lunar/14`/`lunar/09`）

### 10.1 从"进口替代"到"出口经济"的逻辑

2045 年本地化率触及结构性天花板（价值口径 ~55–65%），继续压榨进口替代的边际收益递减；而 lunar/00 §11 条件 3 要求商业收入覆盖维持费 ≥20%（≥$0.2B/年）。**出口制造是该收入项中唯一可规模化的物质性来源**（其余为旅游/科研服务/数据，见 `lunar/09`）。月球出口的三块物理优势：

- **位置**：月面→地月空间任意点的 Δv 远小于地球表面出发（月面→EML1 ~2.5 km/s，无大气、可低加速）；lunar/00 §8 已将推进剂定位为出口项；
- **产能**：MRE（2045 金属 550 t/年 vs 自用 <100 t）与光伏产线（≥400 kWe 铭牌/年 vs 内部扩容 ~50–100 kWe/年）在 2045 后即为过剩产能；
- **工艺环境**：真空镀膜/提纯（§4）与无尘暴的大型露天作业面。

### 10.2 产品路线图（2045–2050+）

| 产品 | 目标市场 | 启动前提 | 时间 |
|---|---|---|---|
| **推进剂（LOX/LH₂，PSR 水）** | EML1/EML2 加注站、火星船队（`lunar/14` 地火协同） | PSR 储量证实 + 加注站在轨演示；lunar/00 §8 已定出口项 | 2045–2048 |
| **光伏板/电力系统** | GEO/高轨卫星、空间太阳能电站组装、深空任务电源 | 产线效率达标（≥12%）+ 月面发射成本（摆渡船复用，远期电磁发射评估） | 2046–2050 |
| **结构件（铝梁/纤维复材/玻璃构件）** | 大型空间结构（km 级桁架、天线、遮光罩） | MRE 富余产能 + 需求方出现 | 2048+ |
| 高纯材料/镀膜服务（远期选项） | 地面超高纯/超净工艺利基市场 | 返程舱位过剩 + 单位价值 >$10k/kg | 2050 后评估 |

### 10.3 前提与边界（诚实清单）

- **需求不确定是最大风险**：地月经济 2040 年 $100B+ 的预测（lunar/00 §1）若落空，出口产品没有买家——出口路线**不作为 2045 自持三条件之一**（lunar/00 §8 已明确推进剂出口"不作为自持条件"），本版同样处理；
- **资源冲突**：PSR 水冰同时是自用 C/N/H 战略储备与出口推进剂原料，出口规模必须服从储量评估（`lunar/11` 第一资源风险）；
- **经济性门槛**：出口品月面离岸成本须 < 地球出发等效成本 ~50% 才有稳定竞争力；按 lunar/00 §6 运输曲线，推进剂 2045 年达标概率高，光伏板取决于月面发射（电磁/复用摆渡）成本曲线；
- 叙事边界：**2045 年的月球是进口替代完成体，2050 年的月球镇是出口经济起步体**——2050 口径下出口制造"已开始、未定型"。

## 12. 风险与开放问题

|---|---|---|---|

## 13. 与 lunar/00 的一致性说明

- 时间线（2031=12 / 2033=30 / 2036=60 / 2040=120 / 2042=160 / 2045=250 / 2050=450 人）、各年着陆质量、运输单价曲线（$0.8M→$0.5M→$0.35M/t）、电力装机（1→2→3→4→5→6+1 MWe）全部直接引用 00 号表格，无修正；
- B5' 参数（8 t/40 kWe、数量 80%/价值 50%、2038–2040 部署）逐字采用 lunar/00 §3-B5' 口径；**MRE 产能/功率采用 `lunar/04` §4.3、光伏产线采用 `lunar/03` §5.3**，本文档仅补充下游精炼成形与供应链口径，无修正；
- 制造相关电力（车间+光伏产线 ~250 kWe + MRE ~700 kWe，2045）合计 ~950 kWe，含于 00 号 §7"ISRU/工业 ~1.5 MWe"配额内（**非修正**，既定配额的领域细化）；
- 2045 自持条件 1 的"建材 ≥90%、光伏板 100% 本地"由本文档 §3/§8 提供实现路径；"补给 ≤0.25 t/人/年"中制造域残余占 ~0.006–0.009 t/人/年，其余配额留给 `lunar/06`（食物补剂/C/N 补充）与 `lunar/08`（个人物品），建议 `lunar/13` 做加总核对；
- §10 出口制造的"推进剂出口不作为自持条件"直接沿用 00 号 §8 结论，收入端测算归 `lunar/09`。
