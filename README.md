# 火星基地推演 · Mars Base

**一套工程自洽的科技预测文档集，含两个平行版本**：

- **`baseline/`（基准版）**：基于 2026 年 8 月技术现状 + 十年尺度自然演进。2035 窗口首批乘员、2045 年 80 人、2045 年"准自持"（一条标准需显式乐观修正）。
- **`breakthrough/`（乐观版）**：假设五大领域近期取得决定性突破（MWe 级空间堆、电合成食物、辐射医学、通用施工机器人、本地电子制造）。2033 窗口首批乘员（提前 26 个月）、2045 年 160 人、**2042 年严格自持**（阈值收紧且无需乐观修正）。

两版**章节同构**（00–13 一一对应，breakthrough 多一份 14-回退路径），每份 breakthrough 领域文档开头都有"相对 baseline 同名文档的结论变化清单"，差异可追溯。

> **性质声明**：这是推演/预测，不是计划书。事实锚点（Starship V3、MOXIE、NASA FSP、火星水冰数据等）均附来源链接并截至 2026 年 8 月；联合体、预算、突破参数均为设定。baseline 回答"现实路径上哪里会卡"；breakthrough 回答"如果那五件事成了，世界长什么样"——**breakthrough 是突破投资回报的愿景说明书，不是预测**。

## 两版关键数字对比

| | baseline（基准版） | breakthrough（乐观版） |
|---|---|---|
| 首批乘员 | 2035 底出发 / 2036 中着陆，12 人 | **2033 底出发 / 2034 中着陆，16 人** |
| 2045 年人口 | 80 人 | **160 人** |
| 2045 年电力 | ~1.45 MWe（裂变 950 kWe + 光伏） | **~4.0 MWe（4×1 MWe 堆 + 1 备用）** |
| 累计着陆质量 | ~3200 t / 40 船次 | ~3190 t / 46 船次 |
| 项目总预算 | ~$180B（年均 $10B） | **~$150B**（峰值前移 2029–2032，$12B/年） |
| 自持达成 | 2045 年"准自持"（C2 需 2 项乐观修正，0.7 vs 0.5 t/人/年；严格自持 ~2050） | **2042 年严格自持**（食物 ≥95%、≤0.33 t/人/年、$1.4B/年，三条件无修正达标） |
| 最紧约束 | 电力扩张节奏 + 轨道加注 | B1 首堆 2029 交付 + 居住建造速度 |
| 最大财务风险 | 硬件超支（×1.5 → +28%） | 突破研发失败 × 预算已按乐观口径压缩的双重暴露 |

## 五大突破速览（breakthrough/00 §1）

| # | 突破 | 关键参数 | 兑现时点 | 撬动 |
|---|---|---|---|---|
| B1 | 紧凑型 MWe 级空间裂变堆 | 1 MWe/台、≤30 t、落地 90 天并网 | 2029 首台交付、2030 着陆 | **登陆日期**（唯一能把上人提前到 2033 的突破） |
| B2 | 电合成食物 | ≤8 kWh/kg 干粉、~90 W/人 | 2034 火星投产 | 食物热量自给 95%、C2 缺口坍缩 |
| B3 | 辐射医学 + 主动屏蔽 | 风险等效 ×3、转运剂量 -40% | 2031/2032 | 驻留 6–9 年、"一人一次"解除 |
| B4 | 通用施工机器人 | L4 周任务单自主、产出 ×2 | 2030 火星实证 | 预部署产出、人口上限 |
| B5 | 本地电子制造 | 备件按数量 80% 本地 | 2040 部署 | "芯片永远进口"被推翻 |

**回退逻辑一句话**：B1/B4 决定"早两年"，B2/B5 决定"好三年"，B3 决定"活得舒服"——而 baseline 决定"最坏情况也不坏"。详见 `breakthrough/14-回退路径.md`。

## 推荐阅读路径

1. **快速了解**（45 分钟）：本 README → `baseline/12` + `baseline/13` → `breakthrough/12` + `breakthrough/13` + `breakthrough/14`。
2. **技术深入（单版）**：先读该版 00 号统一口径，再按兴趣选读 01–11（每篇独立成篇）。
3. **对比视角**：任选一领域，对照两版同名文档——breakthrough 版开头的"结论变化清单"就是为这个读法设计的。
4. **评审视角**：`baseline/11`（风险）→ `breakthrough/11`（突破依赖风险）→ `breakthrough/09` §7.4（财务双重暴露）→ `breakthrough/14`（回退纪律）。
