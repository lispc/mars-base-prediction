# 火星基地推演 · Mars & Moon Base Prediction

**一套工程自洽的科技预测文档集，含三个平行版本**：

- **`baseline/`（火星基准版）**：基于 2026 年 8 月技术现状 + 十年尺度自然演进。2035 窗口首批乘员、2045 年 80 人、2045 年"准自持"（一条标准需显式乐观修正）。
- **`breakthrough/`（火星乐观版）**：假设五大领域近期取得决定性突破（MWe 级空间堆、电合成食物、辐射医学、通用施工机器人、本地电子制造）。2033 窗口首批乘员（提前 26 个月）、2045 年 160 人、**2042 年严格自持**。
- **`lunar/`（月球版）**：与 breakthrough 同一世界观（五大突破同样兑现），目标月球基地。2031 年首批常驻、2045 年 250 人**严格自持**、**2050 年 450 人"月球镇"**。

三版**章节同构**（00–13 一一对应；breakthrough 多 14-回退路径，lunar 多 14-地火协同展望），每份后出版本领域文档开头都有"相对前版同名文档的结论变化清单"，差异可追溯。

> **性质声明**：这是推演/预测，不是计划书。事实锚点（Starship V3、MOXIE、NASA FSP、火星水冰、LCROSS 挥发分、Artemis/嫦娥最新进展等）均附来源链接并截至 2026 年 8 月；联合体、预算、突破参数均为设定。baseline 回答"现实路径上哪里会卡"；breakthrough/lunar 回答"如果那五件事成了，世界长什么样"——**后两者是突破投资回报的愿景说明书，不是预测**。

火星的风险被"26 个月无救援"放大，月球的风险被"3 天可撤离"系统性降级。

## 推荐阅读路径

1. **快速了解**（1 小时）：本 README 对比表 → `lunar/12` + `lunar/13`（最新、节奏最快的一版）→ `breakthrough/12` + `breakthrough/14` → `baseline/13`。
2. **技术深入（单版）**：先读该版 00 号统一口径，再按兴趣选读 01–11。
3. **对比视角**：任选一领域对照三版同名文档——开头的"结论变化清单"就是为这个读法设计的；`lunar/00` §2 的月火物理差异表是理解全部 lunar 结论的钥匙。
4. **评审视角**：`baseline/11` → `breakthrough/11`（突破依赖风险）→ `lunar/11`（PSR 储量 + 地缘政治专题）→ 各版 09（经济）。

## 口径仲裁记录

- **baseline 版**：2045 电力 1→1.45 MWe；2033 窗口须 +400 kWe 保推进剂满产；食物单项补给超阈值（13 号乐观修正处理）。
- **breakthrough 版**：电力质量口径修正（节省在 $/kWe 不在吨位）；-$30B 构成补齐；ISRU 满产冲刺 2.2 t/日 @580 kWe 均值；新增 2031 非窗口 EDL 验证船；撤销 NTP 建议。
- **lunar 版**：氮损失率 KPI 统一为 0.5%/月现行、0.05%/月 2050 目标（采纳 06 口径，04 已同步修订）；运输窄口径 ~8%（09 为准，含客运完全成本宽口径 ~12%）；人员转运成本曲线按 08 插值细化。
