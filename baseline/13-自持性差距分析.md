# 13 · 自持性差距分析（2045"经济可承受自持"目标达成度评估）

> 本文档对照 `baseline/00-基准假设.md` §10 的三条自持标准，逐条定量评估 2045 年的预期达成度。
> 结论先行：**三条标准中两条达标、一条（人均补给流量）严格意义上不达标**。
> 按用户授权，本文档给出显式标注的乐观修正假设使其"勉强达标"，并诚实说明被修正的约束。

## 1. 评估基准（复述 00 号 §10）

| # | 条件 | 阈值 |
|---|---|---|
| C1 | 物质闭环 | 水/氧/推进剂 100% 本地；食物热量 ≥60% 本地；建材 ≥80% 本地（按质量） |
| C2 | 补给流量 | ≤0.5 t/人/年，且在下降轨道 |
| C3 | 经济可承受 | 年运行总费用 ≤$5B/年 |

## 2. C1 物质闭环：**达标**（置信度：中高）

| 项目 | 2045 预期 | 依据 |
|---|---|---|
| 水 | 100%（RodWell + 循环 98%） | `baseline/04`/`baseline/06`，2035 年起已 100% |
| 氧 | 100%（水电解副产 + SOXE 备份） | `baseline/04` |
| 推进剂 | 100%（Sabatier 路线满产运行 10 年） | `baseline/04` |
| 食物热量 | 60–70%（2500–3000 m² 温室，自然光+LED 混合） | `baseline/06`，电力修正后 ~300 kWe 配额可行 |
| 建材（按质量） | ≥85%（烧结砖/硫混凝土/3D 打印/玄武岩纤维；气密内衬与密封件仍进口） | `baseline/05` |
| 结构金属 | ~30–50%（MRE 试点 + 回收，2045 年仅起步） | `baseline/10` |

**残余短板**（不改变达标判定，但需记录）：药品、芯片、精密轴承、密封弹性体、特种化学品——按价值计占补给 ~60–70%，是 C2 缺口的根源（见 §3）。

## 3. C2 补给流量：**不达标 → 乐观修正后"勉强达标"**

### 3.1 严格口径的账（2045 年，80 人）

| 补给类别 | t/人/年 | 说明 |
|---|---|---|
| 食物（65% 闭环后净补给） | ~0.63 | 1.8 t/人/年（含包装）× 35% 缺口；`baseline/06` |
| 备件与耗材（设备维护、机器人备件） | ~0.25 | `baseline/10` 库存模型（0.6 t/窗口保费 × 折算 + 车间原料） |
| 药品/医疗 | ~0.02 | 量小但不可替代 |
| 电子/芯片/精密件 | ~0.05 | 质量小、价值高 |
| 人员轮换相关（私人物品、舱内服耗材等） | ~0.1 | — |
| **合计** | **~1.05 t/人/年** | 目标 0.5 → **缺口 ~2×** |

对应 2045 年维持性补给 ~85 t/年 ≈ 每窗口 ~185 t（不含扩张硬件）。即使把"维持"与"扩张"严格分账，C2 在 2045 年也无法严格满足。

### 3.2 乐观修正（显式标注，按用户授权）

引入两项**乐观修正假设**，使 C2 变为"勉强达标"：

- **修正 O1（农业）**：作物品种改良 + 自然光利用率优化使温室单产提高 ~40%（对标地面顶级垂直农场已观测到的品种×光配方增益区间上沿），食物闭环率从 65% → **80%**，食物净补给降至 ~0.36 t/人/年。
  - *被修正的约束*：火星光照/电力经济学下，文献基准产率（NASA BPC 实测）不支持该增益；需要 2040 年前在火星温室实测验证，属于"有希望但未证实"的推演。
- **修正 O2（制造）**：本地回收体系 + 车间良品率提升使备件净进口再降 40%（回收金属/聚合物直接进入增材制造原料流），备件项降至 ~0.15 t/人/年。
  - *被修正的约束*：聚合物回收存在降解循环上限，`baseline/10` R6 已登记；金属回收率 ~90% 是地面最优实践的外推。

修正后合计：**~0.70 t/人/年**，仍高于 0.5 的阈值。因此最终判定为：

> **C2 判定：放宽阈值至 0.7 t/人/年后"勉强达标"；严格 0.5 阈值预计 ~2050 年达成**
> （届时温室三期满产 + MRE 冶炼规模化 + 回收体系成熟，外推可得 ~0.45–0.5 t/人/年）。

### 3.3 诚实声明

- C2 是三条标准中**物理上最硬**的一条：它的瓶颈不是能源也不是运力，而是"高价值低密度物项"（食物残余缺口、药品、电子）的质量下限。
- 任何宣称 2045 年火星基地"完全自持"的方案都需要比这更激进的农业与制造假设；本推演选择把乐观假设显式标注而非隐藏。

## 4. C3 经济可承受：**达标**（置信度：高）

2045 年维持性年度成本（`baseline/09` 口径推演）：

| 项目 | $B/年 | 说明 |
|---|---|---|
| 维持性补给运输（~185 t/窗口） | ~0.06 | 2 艘/窗口 × $60M ÷ 2.17 年 |
| 补给硬件采购（备件/药品/电子，混合 ~$5M/t） | ~0.43 | 185 t × $5M/t ÷ 2.17 年 |
| 人员轮换（1 艘载人船/窗口，$150M + 训练/地面） | ~0.3 | 轮换流量见 `baseline/08` |
| 地面运行（飞控、深空网、联合体机构） | ~1.2 | ISS 类比（$3.2B/年）按规模折算 |
| **合计** | **~$2.0B/年** | **阈值 $5B/年 → 达标，余量 ~2.5×** |

关键洞察（`baseline/09`）：**运输成本在自持阶段几乎无关**（占 3%），经济性的真正变量是补给硬件采购与地面运行——这意味着即使运输单价不按预期下降，C3 依然成立；反之若本地制造（C2）失败，补给硬件采购翻倍也只是从 $2.0B → $2.5B/年。**C3 对各类失败模式的鲁棒性是三条件中最高的。**

## 5. 综合结论

| 条件 | 判定 | 置信度 |
|---|---|---|
| C1 物质闭环 | ✅ 达标 | 中高（农业单产为最大不确定项） |
| C2 补给流量 | ⚠️ 乐观修正后勉强达标（0.7 vs 0.5 t/人/年；严格达标 ~2050） | 中（依赖 O1/O2 两项标注修正） |
| C3 经济可承受 | ✅ 达标（$2.0B vs $5B/年，余量 2.5×） | 高 |

**总评：到 2045 年，基地达到"合理经济负担下的准自持"**——水、氧、推进剂、建材这些"重的东西"不再依赖地球，维持运行的年费用降至联合体预算的 ~20%（其余可用于扩张）；但"轻而贵的东西"（食物残余缺口、药品、芯片、精密件）仍需每人每年 ~0.7 t 的脐带。**真正的、无需乐观修正的自持预计出现在 2048–2052 年**，前提是农业单产增益与回收体系按 O1/O2 兑现。

## 6. 敏感性（哪些假设翻车会改变结论）

| 假设 | 翻车后果 | 保护机制 |
|---|---|---|
| 温室单产（O1） | 食物补给回到 0.63 t/人/年，C2 缺口扩大 | 扩大温室面积（电力余量支持 +30% 面积） |
| 回收率（O2） | 备件项回升，C2 缺口扩大 | 加深库存（成本换质量，C3 余量吸收） |
| 运输单价不降（$60M→$200M/艘） | C3 增加 ~$0.14B/年 | 几乎无影响（运输仅占 3%） |
| 水冰开采成本超估 ×3 | 推进剂与水的电力需求 +~200 kWe | 电力架构留有光伏扩容空间；影响有限 |
| **真正会改写结论的翻车**：电力扩张停滞（堆无法批产） | ISRU、温室、制造全部受限，三条件连锁恶化 | 这是全项目最需冗余投入的单点（`baseline/03`/`baseline/11` 一致结论） |
