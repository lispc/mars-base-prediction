## 1. 背景与需求

### 1.1 为什么 ISRU 仍是经济支点

单艘货运 Starship 火星着陆质量 ~100 t、2033–2037 年单艘全成本 $100M。若不从火星本地制造
返程推进剂，把 1100 t 推进剂从地球送到火星表面需要 ~12 艘专属货运船（约 $1.2–2.4B 运输成本），
而维持 2 艘常备储备（2200 t）相当于 ~24 艘船的运力。ISRU 工厂全部硬件（~55 t）只需
一艘货运船的一半运力，仍是整个基地经济模型的支点——这一点与 baseline 完全相同。

变化的是**节奏**：B1 使电力从瓶颈变为宽松资源，ISRU 的关键路径从"等电力"变为"等船期"，
满罐时间直接由 2030 窗口船队的到达时间决定（见 §9 倒排）。

第二条需求线**消耗品本地化**不变：2034 年乘员着陆起呼吸氧、饮用/卫生水 100% 本地供应，
以及居住舱/温室缓冲气（N₂/Ar）与 CO₂。2033 起新增第三条线：**ESF 产线的氢/水/CO₂ 原料**
（见 §7）。

### 1.2 资源禀赋（选址：Arcadia Planitia 38–40°N）

- **大气**：~95.3% CO₂、2.7% N₂、1.6% Ar、0.13% O₂，表面气压 ~600–870 Pa（随季节 ±30% 波动）。
  大气是"无限量、零开采成本"的原料，瓶颈在压缩能耗。
- **水冰**：SHARAD 雷达显示浅表（<1 m 覆盖层）大面积水冰，预估冰层纯度 >80%、厚度数米至数十米。
  2028 窗口的核心任务仍是实测验证（见 §10）。
- **温度环境**：日均 ~-60°C，夜间 <-100°C——对低温储存是天然优势，对电解/反应器保温是负担。

### 1.3 需求总量（与 breakthrough/00 对齐）

| 产品 | 2033 年中（Go/No-Go 门）前累计需求 | 稳态需求（2035 后） |
|---|---|---|
| CH₄（推进剂） | 240 t（首艘返程船满罐） | 每窗口 ~240 t（1 艘轮换船消耗 + 储备维持） |
| O₂（推进剂） | 860 t | 每窗口 ~860 t |
| O₂（呼吸） | — | ~13 kg/日（16 人）→ ~150 kg/日（160 人，含泄漏余量） |
| H₂O（开采） | ~540 t（保守设计值，无 RWGS；162–540 t 区间口径不变） | 滚动储备每窗口 ~540 t + 循环损耗 ~0.5–1 t/月 + ESF/农业 |
| H₂（ESF 原料） | — | ~30 kg/日（160 人全量 ESF，见 §7） |
| N₂/Ar（缓冲气） | 居住舱初装 + 泄漏补充 ~2–5 t | 扩容每窗口 ~1–3 t |
| CO₂（温室/ESF 用） | — | 直接从大气取，量级 <5 t/年 |

**储备节奏定义**（breakthrough/00 §5）：2032 年底首艘满罐 1100 t；2033–2035 年建成第二艘
储备，2035 年中起常备 ~2200 t；此后每窗口轮换船离港消耗 1100 t，26 个月内补齐——
即滚动生产速率 **~1.4 t/日（1100 t/窗口）**。

## 2. 大气 CO₂ 获取与压缩

火星大气仅 ~7 mbar，把 CO₂ 送到反应器入口（Sabatier 典型 1–5 bar）压缩比高达 100–700。
方案权衡结论与 baseline 一致，仅规模上调：

- **方案 A：多级机械压缩（涡旋/罗茨组合）**——MOXIE 已验证（涡旋泵 0.6 kPa→~1 bar），
  NASA 实验确认"两级泵压到 1 atm + 5 atm"直接可行
  （[NASA NTRS 20110015862](https://ntrs.nasa.gov/api/citations/20110015862/downloads/20110015862.pdf)）。
  多变压缩 7 mbar→3 bar、30% 效率 → **~0.4 kWh/kg CO₂**
  （[rajpub JAP 9737](https://www.rajpub.com/index.php/jap/article/view/9737/8727)）。
- **方案 B：低温冻结分离**——利用夜间天然冷阱凝华干冰并顺带分离 N₂/Ar，TRL 3–4。
  **本版变化**：电力宽松后其"省压缩功"价值进一步下降（压缩本就只占能量账 <5%），
  不再安排增效示范，仅保留为学术性试验载荷。
- **方案 C：吸附法（PSA/TSA）**——床体庞大、运输质量不划算，不推荐。

**推荐不变：方案 A。** 双列配置（1 用 1 备），满产 55 kg/h CO₂。
规模核验：满产冲刺每产 0.48 t/日 CH₄ 需 1.32 t/日 CO₂，压缩功率 ~22 kWe，
占冲刺总功率 ~3%——选型继续以可靠性为准。压缩机出口冷端仍与 N₂/Ar 低温分离单元耦合回收冷量（§6.3）。

## 3. 制氧路线权衡（含 SOXE 备份线存废论证）

### 3.1 候选方案（物理依据不变）

**方案 A：SOXE 固体氧化物电解（MOXIE 放大）**
- CO₂ + 能量 → CO + ½O₂，~800°C。MOXIE 峰值 12 g/h、纯度 >99.6%
  （[Aerospace America 2025-12](https://aerospaceamerica.aiaa.org/features/a-closer-look-at-spacexs-mars-plan/)）；
  Hoffman 等 2023 优化全尺寸设计 26.9 kW→3 kg/h O₂，**~9 kWh/kg O₂**
  （[ScienceDirect S0094576523002187](https://www.sciencedirect.com/science/article/am/pii/S0094576523002187)）。
- 利：**只需大气**，不依赖水冰链；单一工艺同供推进剂氧与呼吸氧。
- 弊：800°C 陶瓷堆长寿命（>10⁴ h）与热循环密封是公认短板
  （[CORE 154738518](https://core.ac.uk/download/pdf/154738518.pdf)）；比能高于水电解；
  只能产氧，CH₄ 仍需 Sabatier+水电解线。

**方案 B：水电解（PEM/碱性，2035 起增 SOEC）**
- 商用系统 ~50 kWh/kg H₂，折合 **6.25 kWh/kg O₂**
  （[The Space Review 3484](https://www.thespacereview.com/article/3484/1)）。
- 利：兆瓦级成熟工业技术（TRL 9）、常温运行；副产 H₂ 正是 Sabatier 与 ESF 的原料，
  一线三用（§7）；模块化易冗余。
- 弊：绑定水冰开采成败；氢安全管理。

**方案 C：SOXE + RWGS 混合**——RWGS 氢回收可把净采水压到 ~162 t/船，但多一级高温回路。
电力宽松后"多采 380 t 冰"更显便宜（RodWell 热量免费，见 §5），仍不推荐。

### 3.2 电力宽松后 SOXE 备份线是否保留——论证

baseline 保留 SOXE 备份线（2 模块 3 kg/h）的四个理由在 breakthrough 情景下逐条重估：

1. **对冲选址风险（水冰不及预期）**——价值**下降**：2028 窗口 4 艘货船的验证战役规模翻倍
   （B4 机器人作业率 ≥60%，试验钻从 3 口增至 5 口），2030 主产线发货前冰层结论已高度确定；
   且 2032 年底满罐后 RodWell 已实绩运行 18 个月，对冲窗口期已过。
2. **呼吸氧双通道（失效模式多样性）**——价值**不变甚至上升**：2034 年起氧气是生命攸关项，
   SOXE 不依赖水净化/电解槽/氢回路，与水电解无共模故障；这是保留的核心理由。
3. **效率劣势（9 vs 6.25 kWh/kg）**——**不再重要**：呼吸氧需求 13–150 kg/日，
   SOXE 全供的功率代价仅 5–56 kWe，对 1.1–4 MWe 基荷可忽略。
4. **推进剂级产能备份**——**取消**：满产冲刺 72 kg/h O₂ 用 SOXE 备份需 ~20 t 陶瓷堆，
   不如水电解 N+2 模块冗余（+2.7 t）划算。

**结论：保留单模块 1.5 kg/h SOXE**（质量 2.5 t → 1.5 t），定位从"备份线兼呼吸氧主供"改为
"呼吸氧独立备份 + SOXE/CO₂ 化学试验台"。退役条件：2040 年 B5 电子车间达产（控制板/电源
本地可造）且水电解大厅实现 N+2 与本地膜电极更换之后，由 2042 自持评估一并裁决。

**主推路线不变：方案 B（水电解）为主制氧与供氢路线。**

## 4. 推进剂路线与能量总账

### 4.1 路线结论不变

**方案 A：CH₄/O₂ —— Sabatier + 水电解**，与 breakthrough/00 §5 一致：
大气 CO₂ + 水电解 H₂ → Sabatier（CO₂ + 4H₂ → CH₄ + 2H₂O，~300–400°C 镍催化剂，ISS 运行十余年；
NASA 2025 年仍在推进其火星 ISRU 成熟化，[NASA TechPort 93847](https://techport.nasa.gov/projects/93847)）
→ CH₄ 液化；水电解 O₂ → 液化；Sabatier 产水全回用。与 Starship Raptor（LOX/LCH₄）直接匹配。

质量平衡（每艘 1100 t，化学计量）：制 240 t CH₄ 需 H₂ **120 t**、CO₂ 660 t，Sabatier 副产水 540 t
全回用；制 860 t O₂ 需电解水 967 t、副产 H₂ 107.5 t；缺口 12.5 t H₂ 须额外电解 ~113 t 水
（多得 ~100 t O₂ 作消耗品缓冲）。**净采水 ≈ 540 t/船（无 RWGS 保守设计值）**；
162–540 t 的区间口径不变（162 t 对应 RWGS 全回收）。

被否决路线结论不变：纯 CO₂ 电解 CO/O₂（与 Raptor 不匹配，放弃 Starship 体系，仅作"冰不存在"
极端后备）；LOX 本地制 + CH₄ 地球带（每艘 ~2.5 艘船运力溢价、永久依赖补给）。
**本版不再需要 baseline 的"方案 C 过渡形态"**——2030 窗口 B1 堆随队到达，Sabatier 主线
一次到位，无需"先 LOX 后 CH₄"的两步走；先导阶段（2028–2031）改为小规模全线验证（§10）。

### 4.2 能量总账（每艘 1100 t，比能口径与 baseline 相同）

| 环节 | 比能 | 数量 | 能耗 |
|---|---|---|---|
| 水电解（全部 O₂ + Sabatier 用 H₂） | 50 kWh/kg H₂ | H₂ 120 t | ~6.0 GWh |
| CO₂ 压缩 | ~0.4 kWh/kg | 660 t | ~0.26 GWh |
| 水冰开采（RodWell，热量取自堆废热） | ~0.2 kWh/kg（仅泵控，电加热零） | 540 t | ~0.11 GWh |
| O₂ 液化（20% Carnot，RTB） | ~0.36 kWh/kg | 860 t | ~0.31 GWh |
| CH₄ 液化 | ~0.23 kWh/kg | 240 t | ~0.06 GWh |
| ZBO 储存（26 个月） | — | — | ~0.5–0.9 GWh |
| 杂项（热管理/泵/控制，×1.15） | — | — | ~0.9 GWh |
| **合计/艘** | | | **≈ 8.2 GWh → 含裕度取 9–10 GWh（~1.1 MW·年）** |

注：开采项从 baseline 的 0.43 GWh 降到 0.11 GWh——B1 堆废热 ~2–3 MWt 使融冰热量免费
（baseline 的 40 kWe FSP 排热仅 120–160 kWt，只能部分覆盖）。其余各项不变。
文献对照不变：[The Space Review 3484](https://www.thespacereview.com/article/3484/1) 的
~16 GWh/1200 t 口径更高（液化开销与未回用水情景），本文维持 Sabatier 水全回用口径。

**总量视角**：2031–2045 年累计推进剂需求 = 首艘满罐 1100 t + 第二艘储备 1100 t +
~10 个窗口滚动消耗 ~11000 t ≈ **13 000 t 推进剂 / ~110 GWh / 开采水冰 ~6400 t**。
对 4 MWe 级电力系统（2045 年可用 3.5 MWe 基荷）这是 ~15% 的负载占比——电力宽松口径成立。

## 5. 水冰开采（开采量翻倍的井场设计）

### 5.1 路线结论不变：Rodriguez Well 阵列

- NASA/Aerospace Corp 模拟：**10 kW 热输入 → 379 kg/日** 液态水，火星参数优于地球
  （[NTRS 20180007948](https://ntrs.nasa.gov/api/citations/20180007948/downloads/20180007948.pdf)、
  [Hoffman 2016 "Mining Water Ice on Mars"](https://ntrs.nasa.gov/api/citations/20160013682/downloads/20160013682.pdf)）。
  不挖掘不搬土、产出直接是液态水、设备 ~1–2 t/井，仍为最优。
- 退路（冰层不连续→浅表挖掘+封闭升华）与演示项（热钻升华，[MTU 2024](https://www.mtu.edu/honors/research/symposium/booklets/urss-booklet-2024.pdf)）结论不变。
- 前提不变：2028 窗口钻探实测必须确认冰层厚度 ≥3 m、横向延伸 ≥100 m；
  不成立则降级并触发选址修正（联动 `breakthrough/02`）。

### 5.2 开采量翻倍后的井场配置

开采需求分解（540 t/船保守值）：
- **冲刺段（2031 中–2032 底，18 个月）**：540 t ÷ 540 日 ≈ **1.0 t/日** + 消耗品余量 → 设计点 **1.3 t/日**；
- **第二艘储备（2033–2035 中）**：540 t ÷ 790 日 ≈ 0.7 t/日；
- **稳态（2035 起）**：滚动储备 0.7 t/日 + 消耗品补耗 ~0.1 t/日 + ESF/农业扩张 ~0.1 t/日 ≈ **0.9 t/日**；
- **累计（2031–2045）**：~6400 t——单井腔无法容纳此开采量，必须多井轮换。

配置：**井场最终 6 口 RodWell**（baseline 为 3 口）：
- 2030 窗口：井 #1–#4（冲刺段 2 用 + 1 备 + 1 在建/轮换），单井 10–15 kW 热输入、
  400–600 kg/日；2 用井即可覆盖 1.3 t/日设计点下限，第 3 口在线备用对冲单井衰减；
- 2033 窗口：井 #5–#6 + 第二段管网（总量 ~9 t 井场设备）；
- 稳态仅 2 口运行，其余轮换/备用——井腔随开采扩大，单井 2–3 年后产能衰减或塌陷风险上升，
  6 口井按"2 用 2 轮换 2 备"管理，钻机保留 1 台用于补钻新井（每 2–3 窗口 1 口）；
- 井距 ≥100 m 防井腔干扰；管网总长 ~2 km，伴热由堆废热回路供给。

**热源**：B1 堆（1 MWe，~2–3 MWt 排热）引 2–3% 即 40–60 kWt，足够 4 口井满负荷，
且有富余供居住舱预热——热电联供接口相对 baseline 大幅宽松，但仍需在堆设计时预留
热水/热管回路（接口 `breakthrough/03`）。

## 6. 液化与 ZBO 低温储存（2200 t 常备）

### 6.1 液化

- O₂ 液化器：~0.36 kWh/kg（Strobridge 关联，[The Space Review 3484](https://www.thespacereview.com/article/3484/1)），
  冲刺满产 80 kg/h O₂（含 8 kg/h 消耗品盈余）→ 液化功率 ~29 kWe；CH₄ 20 kg/h × 0.23 → ~5 kWe。
  逆布雷顿（RTB）循环仍是大容量最优
  （[NASA ZBO 成熟化 2024](https://indico.cern.ch/event/1296489/contributions/5881467/attachments/2902045/5089874/Maturing%20ZBO%20Tech%20for%20ICEC29%20M%20Meyer%20072424%20final.pdf)）；
  CH₄/O₂ 温区相近共用压缩机平台
  （[ISECG LOX/Methane Gap Assessment](https://www.globalspaceexploration.org/wordpress/docs/Lox%20Methane%20Gap%20Assessment.pdf)）。
- 致密化（过冷 ~8.9% 密度增益）仍留船端加注前做，工厂端按 NBP 液体储存。

### 6.2 ZBO 储存（罐群翻倍）

- 储量：**常备 2200 t**（2 × 1100 t）分存于 **12 座球罐**（每罐 200–300 t；
  LOX 1141 kg/m³ → 860 t/艘 ≈ 755 m³，LCH₄ 422 kg/m³ → 240 t/艘 ≈ 570 m³；
  按 8 座 LOX + 4 座 LCH₄ 配置）。
- 热漏与制冷：覆土 1–2 m 后稳态热漏 <200 W/罐；RTB 制冷机（90 K 级，比功率 <15 W/W，
  [NASA/Creare RTB 进展](https://ntrs.nasa.gov/api/citations/20180004709/downloads/20180004709.pdf)）
  每罐 ~3 kWe，**12 罐合计 ~36 kWe**。
- **本版变化**：基荷冗余充足（N-1 后仍有 3.5 MWe，2045）+ 每罐独立制冷 + 罐间冷量互备，
  ZBO 失效风险从 baseline 的"中"降为"低"；无电保底（覆土半地下罐 + MLI，日蒸发 <0.05%）保留。
- 罐区分两期：2030 窗口 6 座（首艘 1100 t），2033 窗口 6 座（第二艘）；
  两期间设隔离阀组，任一罐区失压不牵连另一艘储备——双船储备的失效容忍设计。

### 6.3 缓冲气 N₂/Ar 提取

路线不变：CO₂ 压缩机后级低温精馏（与 Muscatello"压缩-液化分离"概念一致，
[NTRS 20110015862](https://ntrs.nasa.gov/api/citations/20110015862/downloads/20110015862.pdf)）。
每处理 100 kg 大气得 ~2.7 kg N₂ + 1.6 kg Ar；相对 660 t/船 的 CO₂ 主线是顺带产出，
**边际成本近零**。人口加速（2045 年 160 人）+ 城镇级加压空间（2042 起 >5000 m³ 单体）
使缓冲气需求高于 baseline，2045 年前累计 ~15–20 t，需处理 ~500 t 大气，
仍为主线流量的零头，无需扩容主线。

## 7. ISRU–ESF 基础设施共用（接口 `breakthrough/06`）

B2（电合成食物）2033 窗口随货部署、2034 年投产。ESF 两条路线都是 ISRU 的"近邻化工"：

| 共用项 | ISRU 侧现状 | ESF 侧需求 | 共用设计 |
|---|---|---|---|
| **电解大厅** | 4×250 kW 模块，冲刺后利用率降至 ~50% | SCP 氢氧化细菌需 H₂ ~30 kg/日（160 人全量）≈ 1.3 kg/h ≈ **65 kWe 电解当量** | ESF 作为第 5 路负载接入电解大厅母线，**不新建电解装置**；冲刺期（2031–2032）ESF 未投产，无容量冲突 |
| **氢母管** | 电解直供 Sabatier 缓冲球罐（<2 t 存量，氢不落地储存原则不变） | 连续小流量 H₂（SCP 反应器） | 母管加一路减压支路 + 独立切断阀；氢安全分区（橇外布置）不变 |
| **水净化** | RodWell 出水→电解级纯水（多效过滤+蒸馏） | ESF 工艺水 ~0.5–1 kg/kg 干粉（循环使用，补耗小） | 净化装置按 +20% 容量设计，1.2 t 计入质量预算 |
| **CO₂ 压缩** | 双列 55 kg/h（冲刺） | CO₂ 电合成碳水原料 + SCP 碳源，kg/日量级 | 主线零头，不设专机；从压缩机中压级抽气 |
| **电力** | 冲刺 ~580 kWe / 稳态 ~350 kWe | ESF ~15–25 kWe（160 人，breakthrough/00 §4 口径） | 边际接入，不占峰值预算 |

共用原则：**推进剂生产优先级最高**，ESF 与人用消耗品同级次之；电力调度归 `breakthrough/03`，
但 2045 年 60% 裕度下预计永不触发降载。ECLSS 水/氧循环的管理边界不变——ISRU 只补损耗，
循环率目标（水 ≥98%、氧 ~90%）归 `breakthrough/06` 管理。

## 8. 推进剂工厂总体设计

### 8.1 产能与功率

- **冲刺段（2031 年中–2032 年底，18 个月）**：设计点 **2.2 t/日**（O₂ 1.72 t/日 = 72 kg/h、
  CH₄ 0.48 t/日 = 20 kg/h），可用率按 ≥85% 设计（依据：B4 机器人承担巡检维护、
  B1 基荷无昼夜/尘暴波动、N+1/N+2 模块冗余——高于 baseline 隐含值 62.5%）。
  平均功率 **~580 kWe、峰值 ~700 kWe**。
  **对 breakthrough/00 的修正**：breakthrough/00 §2 记"ISRU 满产 ~550 kWe"，对应 ~1.5 t/日；
  按 2030 窗口船队 2031 年中着陆的物理时序，1.5 t/日 × 18 个月仅 ~810 t，加先导预产
  ~150 t 仍不足 1100 t，故满产冲刺速率须为 2.2 t/日（~580 kWe 均值）。
  1.1 MW 可用电力下（ISRU 700 峰值 + 施工 ~300 kWe ≈ 1.0 MW）该修正可行；
  若严格执行 550 kWe 上限，满罐将滑至 2033 年 3–4 月——仍早于 2033 年中验证门，但余量过薄，不取。
- **第二艘储备（2033–2035 中）**：1.4 t/日，平均 ~470 kWe（电力 1.6 MW，裕度大）。
- **稳态（2035 中起）**：滚动 1.4 t/日 + 消耗品；2035 年 SOEC 增效改造后
  （制氢 50→40 kWh/kg H₂，利用堆废热供高温蒸汽）降至 **~350 kWe**，
  落入 breakthrough/00 §5"稳态 300–400 kWe"口径 ✅。

### 8.2 质量预算（火星表面硬件）

| 子系统 | 质量（t） | 说明 |
|---|---|---|
| 水电解大厅（4×250 kW PEM 模块 + 2035 SOEC 增效单元） | 12.0 | 空间级 ~15 kg/kW 含水处理；N+2 |
| Sabatier 反应器（2 用 1 备，20 kg/h 级）+ 冷凝/干燥 | 2.5 | ISS 衍生放大 |
| CO₂ 压缩机组（双列） | 3.0 | 涡旋+罗茨 |
| RodWell 井场 ×6（钻机 1 台、井下加热、泵、管网 2 km） | 9.0 | baseline 3 井 5 t 的扩展 |
| 液化装置（O₂ 29 kW + CH₄ 5 kW，RTB） | 4.5 | |
| ZBO 储罐 ×12（球罐+MLI+制冷机，半地下） | 11.5 | 干重，不含推进剂；分两期各 6 座 |
| SOXE 备份单模块（1.5 kg/h） | 1.5 | 呼吸氧独立备份 + 试验台（§3.2） |
| N₂/Ar 精馏单元 | 0.8 | |
| ESF 接口（氢母管支路、水净化扩容、缓冲罐） | 1.2 | §7 |
| 管路/阀门/控制/备件（~20%） | 9.0 | |
| **合计** | **~55.0 t** | 2028 运 ~8 t（先导）+ 2030 运 ~34 t + 2033 运 ~13 t |

运力核验：2028 窗口 200 t、2030 窗口 300 t、2033 窗口 450 t 着陆质量中，
ISRU 占比均 <12%，与 breakthrough/00 §2 时间表兼容。

### 8.3 成本预算（2026 年美元，粗估）

| 项目 | 金额 |
|---|---|
| 研发与地面验证（2026–2030，含 2.2 t/日级全尺寸地面联试 + SOEC 空间化） | ~$3.2B |
| 硬件制造（先导 + 主线 + 第二罐区 + 备份件） | ~$2.0B |
| 运输（~55 t 摊入窗口货运：2028 价 $2.2M/t × 8 t + 2030 价 ~$1.6M/t × 34 t + 2033 价 $1.1M/t × 13 t） | ~$0.09B |
| 运行与维护（2031–2045，摊入基地运行预算；B4 机器人降低人工） | ~$0.5B |
| **合计** | **~$5.8B（项目总预算 $150B 的 ~3.9%）** |

对照：从地球运送 2200 t 常备推进剂的运输成本 ~$2.4B 且不可持续——ISRU 工厂在第二艘
返程船时即收回投资的结论不变。

### 8.4 消耗品模式（2034 年中乘员着陆起）

- 呼吸氧：水电解支路主供（冲刺后电解大厅利用率仅 ~50%，产能裕量数倍），
  SOXE 单模块热备独立供电回路；16 人 ~13 kg/日 → 160 人 ~150 kg/日。
- 水：RodWell 稳态 2 井运行，补循环损耗 + ESF/农业；水净化归 §7 共用装置。
- 缓冲气：随加压容积扩张按需生产；2042 年城镇级单体（>5000 m³）初装需 ~2–3 t N₂，
  提前一个窗口排产。

## 9. Go/No-Go 满罐验证与产能倒排（2033 年中门）

**硬门**（沿用 baseline 规则、时点前移）：乘员 2033 年底出发以"返程推进剂满罐、纯度与
蒸发率验证合格"为前提，验证须在出发前 ~6 个月即 **2033 年 6 月**完成；未达标则整体滑期
一个窗口至 2035（回退情景见 `breakthrough/14`）。

**验证判据**（2033-06-30 前全部满足）：
1. 罐存计量 ≥1100 t（CH₄ ≥240 t + O₂ ≥860 t，计量误差 ±2%）；
2. 纯度 CH₄ ≥99.5%、O₂ ≥99.6%（Raptor 加注规范）；
3. ZBO 蒸发率 <0.05%/日，连续 90 天观测（2033-04 起）；
4. 产线不停机：验证期继续生产，第二艘储备累计 ≥150 t（证明滚动能力）；
5. 井场剩余可采储量确认 ≥1000 t（井下监测 + 2028/2030 钻探数据反演）。

**倒排时间表**：

| 时点 | 事件 | 累计推进剂 |
|---|---|---|
| 2029 年中 | 2028 窗口先导线投产（SOXE 3 kg/h + 50 kW 电解 + RodWell #1 试验井，150 kWe 光伏） | 0 |
| 2030-11 | 2030 窗口船队出发（5 艘含 B1 首堆 + ISRU 主线 34 t） | ~100 t（先导预产 O₂） |
| 2031 年中 | 船队着陆；B4 机器人 30 天内完成设备就位 | ~150 t |
| 2031-08 | B1 堆并网（90 天口径内）+ ISRU 主线调试完成，**满产启动** | ~160 t |
| 2031-08 → 2032-12 | 满产冲刺 17 个月 × 2.2 t/日 × 85% 可用率 ≈ 950 t | **~1110 t ✅** |
| 2033-01 → 2033-03 | 满罐计量、纯度化验、产线转入第二艘储备生产 | ≥1100 t 维持 |
| 2033-04 → 2033-06 | ZBO 90 天蒸发率观测 | 第二艘 +90 t |
| **2033-06** | **Go/No-Go 评审** | — |
| 2033-11/12 | 首批 16 名乘员出发（2 艘载人船） | 第二艘 +240 t |
| 2034 年中 | 乘员着陆；ISRU 转消耗品 + 滚动储备模式 | — |
| 2035 年中 | 第二艘储备建成，常备 2200 t | **~2200 t ✅** |

**余量分析**：冲刺段名义余量仅 ~10 t（1110 vs 1100），真正的缓冲在验证期——
2033 年 1–6 月产线仍产 ~240 t，即使可用率低至 70%（产出 ~780 t + 先导 150 t = 930 t），
验证期补足 1100 t 仍有 2 个月富余。可用率 <55% 才触发滑期，该概率由 N+2 冗余
与 B4 维护压到低个位数百分比（登记 `breakthrough/11`）。

## 11. 风险与开放问题

| # | 风险 | 等级 | 缓解 |
|---|---|---|---|
| R1 | Arcadia 浅表冰厚度/纯度不及预期（RodWell 前提失效） | **高** | 2028 窗口 5 口试验钻排雷（B4 翻倍）；退路挖掘-升华；极端退路触发 `breakthrough/02` 选址修正 |
| R2 | **B1 堆交付/并网延迟**（替代 baseline 的"2033 电力不到位"） | **高** | 2030 窗口为 B1 首堆设独立船次冗余；若 2030 堆未到，以 150 kWe 光伏维持先导产能，满产滑至 2033 堆到后启动、满罐滑至 2035——即回退为 baseline 节奏，乘员相应滑期（`breakthrough/14`） |
| R3 | 电解槽/反应器长寿命（>2 万小时）高可用率运行 | 中 | N+2 模块冗余、先导期加速老化试验、备件率 20%、B4 机器人巡检维护 |
| R4 | 双船储备期井场储量管理：井腔干扰/衰减超预期，2040 年代累计 6400 t 开采的储量确认 | 中 | 6 井轮换 + 钻机补钻；井距 ≥100 m；井下长期监测（2028 起）；储量红线纳入 Go/No-Go 判据 5 |
| R5 | 尘埃进入压缩机/反应器（尘暴季） | 中 | 两级过滤；尘暴期降负荷（大气 CO₂ 不缺，停机可补；B1 基荷不受尘暴影响，恢复即满速） |
| R6 | ZBO 制冷机失效 → 蒸发损失 | 低（自 baseline 降级） | 每罐独立制冷 + 罐间互备 + 两罐区隔离；基荷 N-1 冗余使"全站失电"近乎消除 |
| R7 | Sabatier 催化剂中毒 | 低 | 进气净化段；ISS 经验移植 |
| R8 | H₂ 泄漏燃爆（含 ESF 支路新增接头） | 低 | 氢不落地储存；ESF 支路独立切断阀 + 氢敏报警；橇外布置 |
| R9 | ESF 与推进剂争用电解容量/纯水的调度冲突 | 低 | 推进剂优先级最高；2045 年电解大厅利用率 <60%，实质无冲突 |

**开放问题**：
1. RodWell 在粉-冰混合地层的长期井壁稳定性与**多井干扰间距**（无地球类比数据，
   2028 试验钻带井下相机与长期监测；6 井阵列的井距是本文新增问题）。
2. SOEC（高温水蒸气电解）在火星环境的长寿命与堆废热耦合设计——2035 增效改造的前提，
   地面验证纳入 2030–2033 研发计划；若不成立，稳态负载维持 ~470 kWe，对 4 MWe 系统仍可承受。
3. 氢平衡副产品策略不变：补 12.5 t H₂ 缺口多产的 ~100 t O₂/船周期作消耗品缓冲；
   RWGS 在电力宽松下进一步失去意义，仅当 R4 储量紧张时重议。
4. 致密化是否在工厂端做（省船端设备、增耗 ~5%），取决于 Starship V3 加注接口最终规范。
5. 2040 后电解槽膜电极/SOXE 陶瓷堆的本地再生边界，移交 `breakthrough/10-本地制造与供应链.md`。
6. ESF 达产后的氢需求峰值（SCP 反应器启停）与 Sabatier 氢缓冲罐的联合调度策略，
   与 `breakthrough/06` 联合定稿。
